Create src/validation/comparison_grid.py with the following functions:

**Function 1: sample_indices_by_metric(ssim_scores, n_samples, strategy='random')**
  - Input: ssim_scores (numpy array of SSIM values), n_samples (int), strategy (str: 'random', 'best', 'worst')
  - Logic:
    - if strategy == 'random': return np.random.choice(len(ssim_scores), n_samples, replace=False)
    - if strategy == 'best': return np.argsort(ssim_scores)[-n_samples:][::-1] (reverse to descending)
    - if strategy == 'worst': return np.argsort(ssim_scores)[:n_samples]
  - Output: array of indices (length n_samples)
  - Assertion: n_samples <= len(ssim_scores), raise ValueError if not

**Function 2: load_image_batch(image_paths, normalize=True)**
  - Input: list of image paths (strings), normalize flag
  - Output: numpy array [N, H, W, 3] with images loaded from disk
  - Logic:
    - Use PIL.Image.open() for each path
    - Convert to numpy: np.array(img)
    - Normalize to [0, 1]: divide by 255 if max > 1
    - Stack into batch: np.stack(images)
  - Error handling: Skip missing files with warning, or raise if any critical path missing

**Function 3: create_comparison_grid(unstained_batch, virtual_batch, real_batch, sample_indices=None, figsize=(15, 12))**
  - Input:
    - unstained_batch: [N, H, W, 3] numpy array in [0, 1] range
    - virtual_batch: [N, H, W, 3] numpy array in [0, 1] range
    - real_batch: [N, H, W, 3] numpy array in [0, 1] range
    - sample_indices: [n_samples] array of indices to display (default: first min(6, N))
    - figsize: tuple (width, height) for figure
  
  - Steps:
    1. Validate sample_indices: if None, use np.arange(min(6, len(unstained_batch)))
    2. n_samples = len(sample_indices)
    3. Create figure: fig = plt.figure(figsize=(figsize[0], figsize[1] * n_samples / 6))
    4. Create GridSpec: gs = GridSpec(n_samples, 3, figure=fig, hspace=0.3, wspace=0.1)
    5. For each row, idx in enumerate(sample_indices):
       a. Column 0 (Unstained): ax0 = fig.add_subplot(gs[row, 0]); ax0.imshow(np.clip(unstained_batch[idx], 0, 1)); ax0.set_title("Unstained" if row==0 else ""); ax0.axis('off')
       b. Column 1 (Virtual): ax1 = fig.add_subplot(gs[row, 1]); ax1.imshow(np.clip(virtual_batch[idx], 0, 1)); ax1.set_title("Virtual H&E" if row==0 else ""); ax1.axis('off')
       c. Column 2 (Real): ax2 = fig.add_subplot(gs[row, 2]); ax2.imshow(np.clip(real_batch[idx], 0, 1)); ax2.set_title("Real H&E" if row==0 else ""); ax2.axis('off')
    6. Return: fig (matplotlib figure object)

  - Assertions:
    - All batches must have same shape[0] (batch size)
    - All batches must be in [0, 1] range (clip to enforce)
    - sample_indices all valid (check max < len(batches))

Import statements required:
