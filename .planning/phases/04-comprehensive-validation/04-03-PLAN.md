Error visualization principles:
- Per-pixel L1 error: abs(Virtual - Real), averaged across RGB channels to get scalar error per pixel
- Expected high-frequency error: scattered red/blue speckles (noise, acceptable)
- Failure signal: large contiguous error regions (structural failure, unacceptable)
- Diverging colormap: RdBu or PuOr with CenteredNorm ensures symmetric visualization around zero error
- Colorbar range: document global max error for context (e.g., "max pixel error = 0.15 across all patches")

Clinical interpretation:
- Cell boundary mismatch → contiguous error regions around nuclei/gland edges
- Color hallucination → localized error in stain color intensity
- Noise hallucination → scattered high-frequency error (acceptable)
</context>

Create src/validation/error_maps.py with the following functions:

**Function 1: compute_per_pixel_error(virtual_patch, real_patch)**
  - Input: virtual_patch [H, W, 3] and real_patch [H, W, 3], both in [0, 1] range
  - Logic:
    1. Compute absolute difference per pixel: diff = np.abs(virtual_patch - real_patch) # [H, W, 3]
    2. Average across RGB channels: error_map = diff.mean(axis=2) # [H, W]
    3. Compute statistics: mean_error = error_map.mean(), max_error = error_map.max()
    4. Return: error_map, mean_error, max_error
  - Assertion: Both inputs must be in [0, 1] range; raise error if out of bounds
  - Docstring: Explain L1 norm rationale and why averaging across channels (treats RGB as unified structure)

**Function 2: create_error_heatmap(virtual_patch, real_patch, colormap='RdBu_r', figsize=(8, 8))**
  - Input:
    - virtual_patch: [H, W, 3] numpy array in [0, 1]
    - real_patch: [H, W, 3] numpy array in [0, 1]
    - colormap: string name of matplotlib colormap (default 'RdBu_r', alternatives: 'PuOr', 'RdYlBu')
    - figsize: tuple (width, height) for figure
  
  - Steps:
    1. Call compute_per_pixel_error to get error_map, mean_error, max_error
    2. Create figure and axis: fig, ax = plt.subplots(figsize=figsize)
    3. Create colormap normalization: norm = mcolors.CenteredNorm(vcenter=0.0, halfrange=max_error)
    4. Display error map with colormap: im = ax.imshow(error_map, cmap=colormap, norm=norm)
    5. Add title: ax.set_title(f"Absolute Error: |Virtual - Real| (mean={mean_error:.4f})", fontsize=12)
    6. Remove axis ticks: ax.axis('off')
    7. Add colorbar: cbar = plt.colorbar(im, ax=ax, fraction=0.046, pad=0.04); cbar.set_label('Pixel-wise L1 Error', fontsize=10)
    8. Return: fig (matplotlib figure object)
  
  - Imports needed: matplotlib.pyplot as plt, matplotlib.colors as mcolors
  - Assertions:
    - All inputs in [0, 1] range
    - halfrange > 0 (must have some error to visualize)

**Function 3: compute_error_statistics(error_maps_list)**
  - Input: list of error_map numpy arrays [H, W]
  - Logic:
    - Compute per-map means: [error_map.mean() for error_map in error_maps_list]
    - Compute per-map maxes: [error_map.max() for error_map in error_maps_list]
    - Aggregate: mean_error, std_error, min_error, max_error across all patches
  - Output: dict with keys: mean_error, std_error, min_error, max_error, n_patches
  - Use numpy: np.mean(), np.std(), np.min(), np.max()

Import statements required:
- import numpy as np

- import matplotlib.colors as mcolors

Add docstrings explaining:
- Why L1 error and RGB averaging
- CenteredNorm rationale for diverging colormaps
- Expected error distribution patterns (noise vs structural)
