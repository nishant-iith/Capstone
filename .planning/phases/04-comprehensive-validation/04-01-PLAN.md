**Function 1: normalize_images_to_01(tensor_array)**
  - Input: numpy or torch array in [-1, 1] or [0, 1] range
  - Output: numpy array in [0, 1] range

  - Input: virtual_batch [B, H, W, 3] and real_batch [B, H, W, 3], both in [0, 1] range

  - Return: ssim_scores (list of floats), psnr_scores (list of floats)
  - Assertion: data_range=1.0 must be explicit; add comment: "Explicit data_range=1.0 prevents metric ambiguity on normalized images"

**Function 3: compute_metrics_per_image(image_path, image_id)**
  - Input: path to image pair, image identifier
  - Output: dict with keys: image_id, ssim, psnr
  - Use compute_metrics_batch internally for consistency

**Function 4: aggregate_metrics(ssim_list, psnr_list)**
  - Input: lists of SSIM and PSNR values
  - Output: dict with mean, std, min, max for each metric
  - Use numpy: np.mean(), np.std(), np.min(), np.max()
  - Return dict format: {ssim_mean, ssim_std, ssim_min, ssim_max, psnr_mean, psnr_std, psnr_min, psnr_max, n_samples}

Create scripts/run_phase4_validation.py with the following structure:

**Main function: run_comprehensive_validation(guarded_ckpt, test_csv, output_dir, device, batch_size=4)**
  - Arguments:
    - guarded_ckpt: path to Phase 3 guarded checkpoint (string)
    - test_csv: path to test set CSV (string, default 'data/test.csv')
    - output_dir: output directory for results (string, default 'reports/phase4_validation')
    - device: 'cuda' or 'cpu' (auto-detect GPU availability)
    - batch_size: batch size for inference (default 4, optimized for memory)

  - Steps:
    1. Create output_dir if not exists: Path(output_dir).mkdir(parents=True, exist_ok=True)
    2. Load guarded model: model = Pix2PixLightning.load_from_checkpoint(guarded_ckpt).gen.eval().to(device)
    3. Load test dataloader: test_loader = get_dataloader(test_csv, batch_size=batch_size, shuffle=False)
    4. Initialize collections: all_ssim = [], all_psnr = [], all_results = []
    5. For each batch in test_loader:
       a. Run inference: with torch.no_grad(): virtual = model(unstained.to(device)).cpu()
       b. Normalize all outputs to [0, 1]: unstained_norm = (unstained + 1) / 2, virtual_norm = (virtual + 1) / 2, real_norm = (real + 1) / 2
       c. Convert to numpy: permute(1, 2, 0) to get [H, W, 3] for metrics computation
       d. Call compute_metrics_batch from src/validation/metrics
       e. Append to collections with image IDs
    6. Aggregate stats: use aggregate_metrics() from src/validation/metrics
    7. Save CSV: pd.DataFrame(all_results).to_csv(f'{output_dir}/phase4_metrics_per_image.csv', index=False)
    8. Return: stats dict with mean/std/min/max for SSIM and PSNR

  - Error handling:
    - Assertion: "test_csv must exist" — check file exists before loading
    - Assertion: "guarded_ckpt must exist" — check checkpoint exists
    - Assertion: "All images must be normalized to [0, 1]" — add checks in loop
