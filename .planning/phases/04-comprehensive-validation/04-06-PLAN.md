# Plan 04-06: Generate Comparison Grids & Error Maps

**Objective**: Generate visual comparison grids and error heatmaps to qualitatively and visually prove model diagnostic reliability.

**Wave**: 2 (depends on metrics CSV from Plan 04-05)

**Dependencies**: Plan 04-05 (metrics CSV must exist)

---

## Tasks

### Task 1: Generate Comparison Grids

<read_first>
- scripts/generate_comparison_grids.py (the grid generation script)
- src/validation/comparison_grid.py (grid module with GridSpec implementation)
- reports/phase4_metrics_per_image.csv (output from Plan 04-05, needed as input)
</read_first>

<action>
**Script**: `scripts/generate_comparison_grids.py`

**Execution command**:
```bash
python scripts/generate_comparison_grids.py \
  --metrics-csv reports/phase4_metrics_per_image.csv \
  --output-dir reports/phase4_validation
```

**What this does**:
1. Reads the metrics CSV generated by Plan 04-05
2. Loads virtual H&E images (cached from Phase 3 or inferred on demand)
3. Loads corresponding unstained and real H&E images from test set
4. Selects three sets of samples:
   - **Random**: 3x3 grid of random test samples
   - **Best cases**: 3x3 grid of images with highest SSIM (best model performance)
   - **Worst cases**: 3x3 grid of images with lowest SSIM (worst model performance)
5. Creates 3-column grids (Unstained | Virtual | Real) for visual comparison
6. Saves three PNG files

**Expected outputs**:
- `reports/phase4_validation/grid_random_samples.png`
- `reports/phase4_validation/grid_best_cases.png`
- `reports/phase4_validation/grid_worst_cases.png`

Each PNG should show 3 rows × 3 columns = 9 image triplets, with clear visual comparison of how well the Virtual image matches the Real H&E.
</action>

### Task 2: Generate Error Maps

<read_first>
- scripts/generate_error_maps.py (the error map generation script, NOW FIXED from Plan 04-05)
- src/validation/error_maps.py (error computation and heatmap visualization)
- reports/phase4_metrics_per_image.csv (metrics CSV, used to rank worst cases)
</read_first>

<action>
**Script**: `scripts/generate_error_maps.py` (with the stub fixed from Plan 04-05)

**Execution command**:
```bash
python scripts/generate_error_maps.py \
  --metrics-csv reports/phase4_metrics_per_image.csv \
  --output-dir reports/phase4_validation/error_maps
```

**What this does**:
1. Reads the metrics CSV to identify worst-performing images (lowest SSIM)
2. Loads virtual and real H&E images for worst-case samples
3. Computes per-pixel L1 error: `abs(virtual - real)` in RGB space
4. Creates heatmap visualization with:
   - `CenteredNorm` colormap (centered on error=0)
   - Diverging colors (blue for low error, red for high error)
   - Colorbar indicating pixel-wise error magnitude
5. Saves individual error heatmaps as PNG files (one per worst-case image)

**Expected behavior**:
- Error maps show pixel-wise differences clearly
- High-error regions (where model diverges most from real H&E) highlighted in red
- Low-error regions (good agreement) shown in blue
- Colorbar and axis labels present on each image

**Expected outputs**:
- `reports/phase4_validation/error_maps/` directory created
- 9+ PNG files saved (one per worst-case index): `0000.png`, `0001.png`, etc.
- Each file ~200KB (typical for matplotlib PNG output)
</action>

<acceptance_criteria>
- [ ] `test -d reports/phase4_validation/error_maps && echo "exists"` (directory exists)
- [ ] `ls reports/phase4_validation/error_maps/*.png | wc -l` >= 9 (at least 9 error maps generated)
- [ ] All PNG files are non-empty: `find reports/phase4_validation/error_maps -name "*.png" -size +50k` lists all 9+
- [ ] Script exits with code 0 (no errors)
- [ ] No "Would save" or "Placeholder" messages in script output (confirms stub was fixed)

</acceptance_criteria>
