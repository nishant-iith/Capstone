Create src/validation/report_generator.py with the following functions:

**Function 1: load_metrics_data(metrics_csv)**
  - Input: path to metrics CSV
  - Output: dict with keys: mean_ssim, std_ssim, min_ssim, max_ssim, mean_psnr, std_psnr, min_psnr, max_psnr, n_samples
  - Logic: pd.read_csv, compute statistics using numpy

**Function 2: load_artifact_scores(artifact_csv=None)**
  - Input: optional path to artifact scores CSV from Phase 3
  - Output: dict mapping image_id to artifact_score
  - If artifact_csv not provided, return None and note in report "Phase 3 artifact scores not available"

**Function 3: compute_ssim_artifact_correlation(metrics_df, artifact_dict)**
  - Input: metrics dataframe and artifact scores dict
  - Output: correlation coefficient (float) and scatter plot figure
  - Logic:
    - Merge metrics_df with artifact scores by image_id
    - Compute Pearson correlation: scipy.stats.pearsonr
    - Create scatter plot: plt.scatter(ssim, artifact_score)
    - Color points by density or SSIM quartile
    - Add trend line if correlation > 0.3
  - Return: (correlation, figure)
  - Interpretation: positive correlation = high SSIM + high artifacts = hallucination risk

**Function 4: interpret_metrics(stats_dict)**
  - Input: metrics stats dict from load_metrics_data
  - Output: interpretation string (markdown)
  - Logic:
    - SSIM: if mean > 0.90: "Excellent"; 0.85-0.90: "Good"; 0.80-0.85: "Acceptable"; < 0.80: "Below threshold"
    - PSNR: if mean > 28: "Excellent"; 24-28: "Good"; 20-24: "Acceptable"; < 20: "Below threshold"
    - Return formatted markdown string with ranges and clinical context

**Function 5: generate_validation_report(metrics_csv, artifact_csv=None, grid_dir='reports/phase4_validation', error_map_dir='reports/phase4_validation/error_maps', output_path=None)**
  - Input: paths to metrics CSV, optional artifact CSV, grid directory, error map directory
  - Output: markdown string (and optionally write to file)
  
  - Steps:
    1. Load metrics and artifact data
    2. Compute correlation if artifact data available
    3. Generate markdown report with sections:
       
       **Section 1: Title and Executive Summary**
       - "# Phase 4: Comprehensive Validation Report"
       - "Generated: {timestamp}"
       - "{n_samples} test patches validated"
       
       **Section 2: Quantitative Results**
       - Table: Metric | Mean | Std | Min | Max
       - Interpretation of SSIM/PSNR values
       - Comparison to literature benchmarks (VISGAB ≈ 0.93 SSIM, ≈ 29 dB PSNR)
       
       **Section 3: Visual Analysis**
       - "See attached comparison grids:"
       - "- grid_random_samples.png: Representative sample"
       - "- grid_best_cases.png: Highest quality patches"
       - "- grid_worst_cases.png: Most challenging patches"
       - "Interpretation: [guidance on what to look for]"
       
       **Section 4: Error Analysis**
       - "Error maps highlight per-pixel discrepancies"
       - "Expected pattern: High-frequency noise (scattered)"
       - "Failure signal: Structural error (contiguous regions)"
       - "Worst-case error maps: See error_maps/ directory"
       
       **Section 5: Hallucination Risk (if artifact data available)**
       - Scatter plot SSIM vs artifact_score
       - Correlation coefficient and interpretation
       - "High SSIM + High artifact = Potential hallucination (perceptually similar but structurally implausible)"
       
       **Section 6: Clinical Interpretation**
       - SSIM meaning: "Structural similarity to ground truth"
       - PSNR meaning: "Pixel-level color/intensity accuracy"
       - Combined interpretation: "Model produces morphologically faithful virtual images"
       
       **Section 7: Validation Verdict**
       - Pass/Fail decision based on thresholds
       - "✓ Mean SSIM ≥ 0.80: {pass/fail}"
       - "✓ Mean PSNR ≥ 20 dB: {pass/fail}"
       - "✓ Visual inspection: {pass/fail}"
       - "✓ Error patterns acceptable: {pass/fail}"
       - Overall verdict: PASS or CONDITIONAL PASS or FAIL
       
       **Section 8: Recommendations**
       - If PASS: "Model is ready for clinical validation"
       - If CONDITIONAL: "Address identified failure modes in {N} patches"
       - If FAIL: "Model requires retraining with focus on..."
    
    4. If output_path provided, write to file: with open(output_path, 'w') as f: f.write(markdown)
    5. Return: markdown string
