**Script**: `scripts/run_phase4_validation.py`

**Execution command**:
```bash
python scripts/run_phase4_validation.py \
  --guarded-ckpt checkpoints/phase3_guarded_model.ckpt \
  --test-csv data/test.csv \
  --output-dir reports/phase4_validation
```

**What this does**:
1. Loads the Phase 3 guarded model checkpoint
2. Loads the test dataset from data/test.csv
3. Runs inference on all test images
4. Computes SSIM and PSNR metrics for each image
5. Saves per-image metrics to `reports/phase4_metrics_per_image.csv`
6. Prints summary statistics (mean, std, min, max for both metrics)

**Expected behavior**:
- Script runs without errors (GPU or CPU, depending on available resources)
- Progress indicators printed as batches are processed
- Summary statistics printed at end showing mean SSIM and PSNR values
- CSV file created with headers: image_id, ssim, psnr
- All test images processed (row count matches test set size)

**If checkpoint or test data missing**:
- The script will fail with FileNotFoundError
- Verify prerequisites exist: `ls -la checkpoints/phase3_guarded_model.ckpt data/test.csv`
- If missing, note in a blockers section and user can decide to skip or provide the data
