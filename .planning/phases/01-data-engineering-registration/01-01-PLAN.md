Implement the core data alignment pipeline to ensure that unstained and stained images are perfectly paired and spatially aligned.

Purpose: Tissue distortion during staining makes raw patches misaligned. This plan corrects those distortions so the GAN can learn a direct pixel-to-pixel mapping.
Output: A set of spatially aligned image pairs.
</objective>

    - Input: Directory containing files with pattern `[ID]_patch_[X]_[Y]_[state].tif`
    - Output: A mapping where `(ID, X, Y) -> (unstained_path, stained_path)`

<task type="auto">
  <name>Task 2: Implement SimpleITK Elastic Registration</name>
  <files>src/data/registration.py</files>
  <action>
    Create `src/data/registration.py`. Implement a registration pipeline using SimpleITK:
    1. Load fixed (stained) and moving (unstained) images.
    2. Configure an `ImageRegistrationMethod` with a B-Spline/Elastic transform.
    3. Use `MutualInformation` as the similarity metric to handle the intensity difference between stained and unstained images.
    4. Execute the registration loop and warp the unstained image to match the stained one.
    5. Save the result to `data/processed/aligned_unstained_[ID]_[X]_[Y].tif`.
  </action>
  <verify>
    <automated>python src/data/registration.py --test-sample</automated>
  </verify>
  <done>Registration pipeline produces aligned images where the unstained morphology matches the stained gold standard.</done>
