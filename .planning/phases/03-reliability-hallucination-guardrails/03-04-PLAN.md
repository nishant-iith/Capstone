Hallucination Indicators (medical image context):
- High-frequency noise (synthetic speckles)
- Spurious cell-like structures (nuclei added/removed where not in unstained source)
- Color artifacts (unnatural H&E color blotches)
- Edge discontinuities (boundaries that don't align with source morphology)

Detection Strategy:
- High-pass filtering (Laplacian or high-frequency components) to isolate artifactual content
- Threshold-based flagging of patches with excessive high-frequency content
- Comparison of baseline vs guarded artifact counts per patch
- Visual side-by-side grids for qualitative verification
</context>

Create a new file `src/inference/hallucination_detection.py` with the following components:

1. **Function: compute_high_pass_filter(image_tensor, kernel_type='laplacian'):**
   - Input: image tensor [batch, channels, height, width] in range [0, 1] or [-1, 1]
   - Normalize if needed: ensure range [0, 1]
   - Convert to grayscale if 3-channel: mean across channel dimension
   - Apply Laplacian kernel: [0, 1, 0], [1, -4, 1], [0, 1, 0] via F.conv2d(padding=1)
   - Output: high-frequency component tensor [batch, 1, height, width]
   - Return: high_pass tensor

2. **Function: compute_artifact_score(generated_image, threshold_percentile=90):**
   - Input: generated image tensor (single image or batch)
   - Compute high-pass filter response
   - Calculate artifact score as: mean absolute value of high-pass output
   - Alternative: percentage of pixels exceeding 90th percentile of high-pass magnitude
   - Output: scalar score (float) per image or per batch
   - Return: artifact_score (positive value, higher = more artifacts)

3. **Function: detect_artifacts(image_batch, artifact_threshold=0.05):**
   - Input: batch of generated images, scalar threshold
   - Compute artifact_score for each image in batch
   - Flag images where score > threshold as "containing artifacts"
   - Output: binary flag array [batch_size], and score array [batch_size]
   - Return: (artifact_flags, artifact_scores)

4. **Function: compute_artifact_reduction(baseline_scores, guarded_scores):**
   - Input: two arrays of artifact scores (baseline and guarded)
   - Calculate: reduction_percentage = (mean(baseline) - mean(guarded)) / mean(baseline) * 100
   - Calculate: count_reduction = sum(baseline > threshold) - sum(guarded > threshold)
   - Output: dict with reduction_pct, count_reduction, baseline_mean, guarded_mean
   - Return: statistics dict

5. **Documentation:**
   - Module docstring: "Detects morphological hallucinations using high-frequency artifact analysis"
   - Function docstrings for each function with parameter descriptions

**Implementation Details:**
- Use F.conv2d for Laplacian filtering (torch.nn.functional)
- Normalize high-pass output by Laplacian kernel sum (optional, for stability)
- Artifact score is intuitive: higher = more spurious content
- Threshold value (~0.05 or tunable) flags patches with excessive high-frequency noise
- Score reduction between baseline and guarded is the key metric (D-07)
