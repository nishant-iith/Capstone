Create a new file `src/training/structural_loss.py` with the following components:

1. **Sobel Edge Filter Setup:**
   - Create horizontal Sobel kernel: [[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]]
   - Create vertical Sobel kernel: [[-1, -2, -1], [0, 0, 0], [1, 2, 1]]
   - Both kernels as torch.Tensor (float32)

2. **Helper Function `compute_sobel_edges(image_tensor)`:**
   - Input: image tensor of shape [batch, channels, height, width] in range [-1, 1]
   - Convert to grayscale if needed (simple averaging: mean across channel dimension)
   - Apply horizontal Sobel filter via F.conv2d with padding=1
   - Apply vertical Sobel filter via F.conv2d with padding=1
   - Combine: edge_magnitude = sqrt(sobel_h^2 + sobel_v^2 + epsilon=1e-8)
   - Return: edge tensor of shape [batch, 1, height, width]

3. **StructuralConsistencyLoss Class (nn.Module):**
   - Inherit from torch.nn.Module
   - In __init__: Register Sobel kernels as buffers (not parameters)
   - Implement forward(fake_images, real_images):
     - fake_edges = compute_sobel_edges(fake_images)
     - real_edges = compute_sobel_edges(real_images)
     - loss = F.l1_loss(fake_edges, real_edges)  # L1 between edge maps
     - return loss (scalar, averaged across batch)

4. **Documentation:**
   - Module docstring explaining: "Penalizes divergence in edge structure between generated and target images."
   - Parameter docstring for forward(): shape expectations and return type

**Implementation Details (per D-02 structural loss weight = 10):**
- Loss computation is unnormalized (weighting applied externally in lightning_module.py as λ_struct * L_struct)
- Use grayscale conversion (no channel-specific edge detection needed for structural consistency)
- No activation functions applied to edge outputs (let raw Sobel values drive loss)
